# BatteryGuardian AI — Flutter Mobile Application & Storage Documentation

## 1. Mobile Application Architecture

The BatteryGuardian AI Flutter mobile application connects directly to the ESP32 hardware via Bluetooth Low Energy (BLE), parses incoming JSON telemetry streams, maintains a local historical time-series database in SQLite, and presents a startup-grade battery intelligence dashboard.

```
       +-----------------------+
       |   ESP32 BLE GATT      |
       |  (1 Hz JSON Telemetry)|
       +-----------+-----------+
                   |
                   v
       +-----------------------+
       |      BleService       |  (flutter_blue_plus: MTU 256,
       |  (Stream Controller)  |   Notify subscription)
       +-----------+-----------+
                   |
         +---------+---------+
         |                   |
         v                   v
+-----------------+ +-------------------+
| DatabaseService | |  BatteryProvider  |
| (Local SQLite)  | |(State Management) |
+--------+--------+ +---------+---------+
         |                    |
         v                    v
+-----------------+ +-------------------+
| CsvExportService| | Flutter UI Screens|
| (One-click CSV) | | - Dashboard       |
+-----------------+ | - Live Charts     |
                    | - History Logs    |
                    | - Digital Passport|
                    +-------------------+
```

## 3. SQLite Database Schema & Raw Storage Policy

All raw telemetry is stored without loss to support future model training, hardware validation, and calibration:

```sql
CREATE TABLE telemetry (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp INTEGER NOT NULL,
    battery_id TEXT NOT NULL,
    cell1_voltage REAL NOT NULL,
    cell2_voltage REAL NOT NULL,
    cell3_voltage REAL NOT NULL,
    pack_voltage REAL NOT NULL,
    current REAL NOT NULL,
    power REAL NOT NULL,
    temperature1 REAL NOT NULL,
    temperature2 REAL NOT NULL,
    temperature3 REAL NOT NULL,
    avg_temperature REAL NOT NULL,
    cell_imbalance REAL NOT NULL,
    discharged_mah REAL NOT NULL,
    charge_discharge_state TEXT NOT NULL,
    cycle_number INTEGER NOT NULL
);

CREATE INDEX idx_telemetry_ts ON telemetry(timestamp);
CREATE INDEX idx_telemetry_cycle ON telemetry(cycle_number);
```

## 5. How to Run the Flutter Application

### Prerequisites:
* Flutter SDK (v3.19+ recommended)
* Android Studio / Xcode
* Real Android or iOS device with Bluetooth turned on (BLE requires physical hardware; emulators do not support physical BLE scanning)

### Steps:
1. Navigate to the app directory:
   ```bash
   cd mobile_app
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run on your connected smartphone:
   ```bash
   flutter run
   ```
4. In the app:
   * Tap **Connect** on the dashboard.
   * Select `BatteryGuardian-ESP32`.
   * Watch live cell voltages, current, temperatures, and Health Score populate in real-time.
   * Navigate to **History & CSV** to view SQLite records or tap **Export CSV** to share data files directly to your computer or cloud storage.
